🌦️ Modern Weather App
A sleek, real-time weather application built with React and Tailwind CSS 4. This project provides users with instant weather updates, featuring a dynamic UI that adapts to current atmospheric conditions.

✨ Key Features
Real-Time Updates: Fetches live data from the OpenWeatherMap API. 📡

Dynamic Backgrounds: The app's theme changes automatically (Sunny, Cloudy, Rainy, Snowy) based on the weather. 🎨

Modern UI/UX: Built with the latest Tailwind CSS 4, featuring glassmorphism effects and smooth transitions. 💎

User Friendly: Supports "Enter" key searching and provides clear loading/error states. ⌨️

🛠️ Tech Stack
Frontend: React.js, Tailwind CSS 4, Axios

Backend: Node.js & Express (API Proxy to keep the API Key secure) 🛡️

🚀 Getting Started
Clone the repository:

Bash

git clone [YOUR_REPOSITORY_URL]
Install dependencies:

Bash

npm install
Run the application:

Bash

npm run dev
